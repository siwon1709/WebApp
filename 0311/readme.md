## 📑 웹 프로그래밍 및 React 기초 학습 보고서

# 1. 웹 개발의 기초: HTML & CSS
# 1.1 HTML과 메타데이터
HTML (Hyper Text Markup Language): 웹 페이지의 뼈대를 구성하기 위해 사용하는 마크업 언어입니다
마크업 언어 vs 메타데이터: 마크업 언어가 문서의 구조와 표현 방식을 정의한다면, 메타데이터는 데이터 자체를 설명하는 정보(속성, 의미, 관계 등)를 제공합니다
HTML 표준 기구: W3C(공식 명세 제공), MDN(상세 가이드 및 예제), WHATWG(최신 Living Standard 유지보수) 등이 웹 표준을 주도하고 있습니다

# 1.2 디자인과 생산성 도구
CSS (Cascading Style Sheets)**: 웹 페이지의 레이아웃, 글꼴, 색상 등 시각적 디자인을 담당합니다
Emmet: HTML, CSS 마크업 코드를 짧은 문법으로 빠르게 작성할 수 있도록 돕는 자동 완성 도구입니다

## 2. 웹 애플리케이션 구조 및 실행 환경
# 2.1 MPA vs SPA 비교
웹 애플리케이션의 구동 방식은 크게 두 가지로 나뉩니다

MPA (Multi-Page App) | SPA (Single-Page App)
새로운 페이지 요청 시마다 서버에서 HTML을 받아옴 | 초기 1회 로드 후, 필요 데이터만 AJAX로 받아 갱신
SEO 및 초기 로딩 시 유리  | 전환 속도가 빠르고 사용자 경험(UX)이 우수함

# 2.2 Node.js의 정의와 역할
런타임 환경: Node.js는 브라우저 외부(서버 측)에서 자바스크립트를 실행할 수 있게 해주는 **런타임 환경**입니다
성격: 특정 OS에 종속되지 않는 실행 환경을 제공하며, 특정 개발 방식(아키텍처)을 강요하지 않는다는 특징이 있습니다

# 3. 개발 도구 및 빌드 도구 (IDE & Build Tools)
IDE (Integrated Development Environment): 코드 편집, 디버깅, 빌드 등을 하나로 통합한 도구로, 대표적으로 **Visual Studio Code(VS Code)**가 널리 쓰입니다

패키지 매니저:
npm: 패키지를 설치하고 관리하는 매니저입니다
npx: 패키지를 설치하지 않고 바로 실행할 수 있게 돕는 도구입니다
빌드 도구 (Vite vs Webpack): 최근에는 Webpack보다 개발 서버 속도가 훨씬 빠른 Vite가 차세대 프론트엔드 빌드 도구로 주목받고 있습니다

# 4. React와 JSX
# 4.1 JSX (JavaScript XML)
JSX는 자바스크립트 코드 내에서 HTML과 유사한 문법을 사용할 수 있도록 만든 문법 확장입니다. 이는 Babel을 통해 일반 자바스크립트(`React.createElement`)로 변환됩니다.

# 4.2 JSX의 주요 특징 및 사용법
1. 가독성: HTML과 유사한 구조 덕분에 직관적이고 유지보수가 쉽습니다
2. 부모 요소 규칙: 반드시 하나의 부모 요소(혹은 Fragment `<> </>`)로 감싸야 합니다
3. 자바스크립트 결합: 중괄호 `{}`를 사용하여 변수나 표현식을 직접 삽입할 수 있습니다
4. 속성 정의: `class` 대신 `className`, `for` 대신 `htmlFor`를 사용하며, 스타일은 객체 형태로 전달합니다
5. 조건부 및 반복 렌더링: 삼항 연산자나 `&&` 연산자를 활용하며, 배열의 경우 `map()` 함수와 고유한 `key` 값을 사용하여 렌더링합니다
