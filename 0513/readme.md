1. 개요
본 발표는 Windows의 기본 웹 서버인 IIS(Internet Information Services)를 활용하여, 기획한 서비스인 '부산 로컬 플레이스'의 핵심 기능을 단계적으로 구현하는 과정을 다룬다. 웹 서비스의 기초적인 구조 이해부터 데이터베이스 연동까지의 흐름을 통해, 실제 서비스 구축을 위한 기술적 토대를 학습하는 데 목적이 있다.

2. 프로젝트 목표 및 시나리오
프로젝트명: 부산 로컬 플레이스 (Busan Local Place)

기획 의도: 부산 지역의 신뢰도 높은 여행 정보 및 로컬 콘텐츠 허브 구축

기술적 목표:

IIS 환경에서의 웹 서비스 호스팅 및 실행 흐름 파악

사용자 인터랙션(Todo), 외부 API 파싱(날씨), 데이터베이스(리뷰) 연동을 통한 풀스택 구조의 이해

3. 웹 서비스 구축 단계별 구현 내용
3.1. IIS 환경 구성 및 기초 설정
구현 내용: Windows 운영체제에서 IIS 기능을 활성화하고, C:\inetpub\wwwroot 경로에 웹 콘텐츠를 배치하여 서비스 구동 확인.

핵심 가치: 웹 서버의 역할을 이해하고, 브라우저의 요청이 서버를 거쳐 HTML을 클라이언트로 응답하는 기본 메커니즘을 시각화.

3.2. PRD 기반 핵심 기능 구현
기획된 PRD(Product Requirements Document)의 MVP 핵심 기능들을 최소 단위(Prototype)로 구현하여 기술적 타당성을 검토한다.
