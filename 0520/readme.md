
1. 프로젝트 개요
프로젝트명: 부산 로컬 플레이스 (가칭)

비전: 부산을 찾는 여행자와 지역 주민에게 신뢰할 수 있는 맛집·여행 정보를 제공해 웹과 유튜브를 통한 지역 콘텐츠 허브로 성장

핵심 문제:

부산 관련 정보가 분산되어 있어 신뢰할 만한 최신 리뷰·영상 접근이 어려움

숏폼 중심 소비 트렌드에 맞는 시각적 콘텐츠 부족

2. 목표 및 KPI
지표	목표값	측정방법
월간 순방문자	50,000	Google Analytics
유튜브 구독자	30,000 (6개월)	YouTube Analytics
페이지 평균 체류시간	≥ 2분	Google Analytics
콘텐츠 전환율 (글→구독)	≥ 3%	UTM 트래킹
SNS 공유 수	게시물당 ≥ 50회	소셜 리포트/UTM


3. 타깃 페르소나
페르소나 A (직장인, 25–34세)

니즈: 분위기 좋은 식당 탐색 및 예약

시나리오: 검색 → 리뷰 확인 → 숏폼 시청 → 예약 클릭

페르소나 B (여행 애호가, 18–30세)

니즈: 당일치기 코스·인생샷 스팟 탐색

시나리오: 숏폼 시청 → 웹 상세 확인 → SNS 공유

4. 핵심 기능 (MVP)
P0 (필수)

심층 리뷰 페이지 (메뉴·가격·추천·예약팁·현장 사진)

숏폼 임베드 (유튜브 쇼츠 자동 연동)

검색·필터 기능 (지역·분위기·가격대·식사 유형)

CMS 기반 워크플로우 (작성→검수→게시)

SEO 기본 세팅 (메타·스키마·오픈그래프)

관심 장소 저장 기능 (Todo 형태)

외부 API 연동 (부산 날씨·관광지 API)

P1 (우선 도입)

여행 코스 가이드 (반나절·1일·2일 루트)

댓글·별점 기능

유튜브 채널 업로드 가이드

P2 (향후 고려)

사용자 사진 업로드·UGC 갤러리

예약·배달 API 연동

다국어 지원

5. 비기능 요구사항
모바일 우선 반응형 디자인

페이지 로드 ≤ 2초 (CDN 활용)

WCAG AA 접근성 준수

개인정보 최소 수집 (옵트인 방식)

6. 타임라인 (90일 로드맵)
주 0–2: 브랜드 네임 확정, 도메인·호스팅, CMS 설계

주 3–6: 콘텐츠 제작 (글 20개, 숏폼 5개)

주 7–8: 베타 런칭, SEO 적용, 초기 배포

주 9–12: 데이터 분석, A/B 테스트, 콘텐츠 우선순위 조정

7. 리스크 및 대응
초기 트래픽 부족 → 유료 SNS 광고·인플루언서 협업

콘텐츠 신뢰성 문제 → 현장 사진·업체 확인·출처 표기

영상 제작 병목 → 숏폼 템플릿화·체크리스트 활용

경쟁 심화 → 롱테일 키워드·니치 시장 집중 (혼밥·비건·가성비)

8. 출시 기준 및 다음 단계
출시 기준

초기 콘텐츠 (글 20 + 숏폼 5) 업로드

SEO 및 GA/YouTube 연동 완료
