# 📘 2026년 1학기 웹 프로그래밍 응용  

## 1. 교과목 개요  
본 교과목은 모바일 웹 환경에서 동작하는 웹 애플리케이션 구현 능력을 기르는 것을 목표로 한다. 강의계획서에서는 이 과목을 다음과 같이 정의한다.

> “HTML, Javascript, CSS 및 서버 프로그램의 동작 원리와 구현 방법을 프로그래밍 실습을 병행하여 학습합니다.”

즉, 단순한 웹 페이지 제작을 넘어 **모바일 환경을 고려한 실전형 웹 개발 능력**을 키우는 데 초점이 맞춰져 있다.  
또한 방학 중 특강 신청을 언급한 것으로 보아, 심화 학습 기회도 제공되는 실용 중심 과목임을 알 수 있다.

## 3. 선수과목  
선수과목은 **HCJ(HTML, CSS, JavaScript)**이다.

## 6. 수강 시 주의사항  
강의계획서에서는 다음과 같은 조건을 명시한다.

> “영타 300, Github 관리, 발표 수업, 두 번 이상 지각이나 한 번 이상 결석 시 A 그룹에서 제외”

이는 웹 개발 실습 수업의 특성상 **타이핑 속도, 꾸준한 출석, Github 관리 능력**이 매우 중요하다는 의미다.  
특히 A 그룹 제외 규정은 성실성과 참여도를 강하게 요구하는 구조다.

## 7. 주차별 학습 계획 분석  

### 1~7주차: React 핵심 개념 집중 학습  
- 자바스크립트 기초 복습  
- JSX  
- 컴포넌트, Props  
- State, 생명주기, Hooks  
- 이벤트 핸들링  
- 조건부 렌더링  
- 리스트, 키, 폼  
- State 끌어올리기, 합성 vs 상속, Context  

이 구성은 React 공식 문서의 학습 흐름과 거의 동일하며, **React의 기본기부터 고급 개념까지 체계적으로 학습**하도록 설계되어 있다.

### 8주차: 중간고사  
React 기초 및 컴포넌트 구조 이해를 평가할 가능성이 높다.

### 9~12주차: 서버 기술 학습  
- Node.js  
- ASP  
- PHP  
- JSP  

React 기반 프론트엔드뿐 아니라 **다양한 서버 기술을 비교 학습**하는 점이 특징이다.  
이는 학생이 특정 기술에만 의존하지 않고, 웹의 전체 구조를 이해하도록 돕는다.

### 13~14주차: 프로젝트  
2주간 프로젝트를 진행하며, 실제 웹 애플리케이션을 구현하는 실전 단계이다.  
React + 서버 기술을 조합한 **풀스택 미니 프로젝트**가 될 가능성이 높다.

### 15주차: 기말고사  
서버 기술 및 전체 웹 구조 이해를 평가할 것으로 예상된다.

## 8. 강의의 특징 및 기대 효과  

### 1) 모바일 환경 중심의 실전형 웹 개발  
강의계획서에서 “모바일 웹 환경에서 동작하는 애플리케이션 구현”을 강조하고 있어, 반응형 UI, 모바일 최적화 등 실무 요소를 다룰 가능성이 크다.

### 2) React + 서버 기술의 통합 학습  
프론트엔드와 백엔드를 모두 경험함으로써 **웹 전체 구조를 이해하는 개발자**로 성장할 수 있다.

### 3) Github 기반의 개발 습관 형성  
30%라는 높은 비중은 학생이 실제 개발자처럼 버전 관리하는 능력을 갖추도록 유도한다.

### 4) 발표 및 프로젝트 중심  
개발 능력뿐 아니라 **문제 해결 과정 설명 능력**, **팀 협업 능력**까지 강화된다.

## 9. 학습 전략 제안  

### ✔ React는 1~7주차에 집중적으로 배우므로, 미리 기본기 다지기  
- JSX 문법  
- 컴포넌트 구조  
- useState, useEffect 등 기본 Hooks  

### ✔ Github는 매주 꾸준히 관리  
- 커밋 메시지 규칙 만들기  
- 브랜치 전략 간단히 적용해보기  

### ✔ 서버 기술은 비교 관점으로 접근  
Node, ASP, PHP, JSP는 모두 역할은 같지만 구조가 다르므로  
“왜 이런 방식으로 동작하는가?”를 중심으로 학습하면 이해가 빠르다.

### ✔ 프로젝트는 React + 서버 기술을 조합한 형태로 준비  
예:  
- React + Node.js  
- React + PHP  
- React + JSP
